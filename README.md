# Spotify Presentation Website

Este repositorio contiene una presentación web estilo "scrollytelling" sobre Spotify, diseñada para ser alojada en GitHub Pages.

## Contenido
La presentación cubre los siguientes puntos:
1.  **Introducción y Contexto**: Historia y datos globales.
2.  **Arquitectura**: Cómo funciona el streaming y el algoritmo.
3.  **Finanzas**: Análisis de ingresos, costos y rentabilidad.
4.  **Competencia**: Comparativa con Apple, Amazon y YouTube.
5.  **Usuarios**: Tendencias y demografía.
6.  **Artistas**: Modelo de pagos y economía.
7.  **Tutorial**: Cómo se construyó este sitio.

## Cómo ver la presentación localmente
1.  Clona este repositorio o descarga los archivos.
2.  Abre el archivo `index.html` en tu navegador web (Chrome, Firefox, Safari).

## Cómo publicar en GitHub Pages
1.  Crea un nuevo repositorio en GitHub.
2.  Sube los archivos de este proyecto (`index.html`, carpeta `css`, carpeta `js`).
3.  Ve a la pestaña **Settings** del repositorio.
4.  En el menú lateral, haz clic en **Pages**.
5.  En **Source**, selecciona `Deploy from a branch`.
6.  En **Branch**, selecciona `main` y la carpeta `/ (root)`.
7.  Haz clic en **Save**.
8.  En unos minutos, GitHub te dará el link de tu presentación.

## Créditos
Diseñado como material educativo para análisis de plataformas digitales.
